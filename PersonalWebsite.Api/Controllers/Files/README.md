# Controllers/Files

This folder contains reference files used during development of the Hello World API feature.

## Contents

| File | Description |
|------|-------------|
| `hello_world_api_prd.pdf` | Original PRD for the Hello World API (Feature 1: `GET /api/hello/{name}`). |
| `hello_world_api_prd_updated.pdf` | Updated PRD covering Feature 2: `GET /api/hello/persons` paged endpoint with multi-error validation. |
| `hello_world_api_prd.txt` | Plain-text version of the original PRD. |
| `hello_world_api_prd_extracted.txt` | Text extracted from the original PRD via `extract_pdf.py`. |
| `extract_pdf.py` | Python script used to extract text content from the PDF files using `pdfminer.six`. |
